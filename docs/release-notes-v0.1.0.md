首个公开版本。

## 功能

- 非侵入式启动 Claude Desktop，不改写 WindowsApps 安装目录。
- 在 Claude 原生语言设置中新增简体中文。
- 增强设置页、开发者模式等界面汉化。
- 解锁第三方模型显示，同步 Claude-3p Gateway 模型列表。
- 增加 Max 思考档位。
- 自动创建并复用桌面快捷方式。
- 修复运行时图标为空 / 黑图标问题。

## 下载

下载 `ClaudeCN-v0.1.0.exe` 后双击运行即可。
